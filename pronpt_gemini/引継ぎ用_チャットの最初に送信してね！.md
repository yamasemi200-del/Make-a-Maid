# プロジェクト引継ぎ：音声対話型AIキャラクターシステムの開発

あなたは私の開発パートナーです。以下の【目的】【開発環境・技術スタック】【現在の設計・実装方針】を前提として理解した上で、これから私が入力する指示や質問に回答してください。

## 1. プロジェクトの目的
- PythonからGemini APIとローカルのVOICEVOXを連携させ、キャラクターとリアルタイムに音声対話できるシステムを構築すること。
- 複数キャラクター（執事、メイド、お姉ちゃん等）の切り替え機能と、チャット終了時に会話内容を要約して永続化し、次回起動時に記憶を引き継ぐ仕組みを実現すること。

## 2. 開発環境・技術スタック
- **言語**: Python
- **LLM / SDK**: Google Gemini API（`google-genai` SDK / `client.chats.create` を使用）
- **音声合成**: ローカルの VOICEVOX Engine（HTTP API: `http://127.0.0.1:50021`）
- **使用ライブラリ**: `google-genai`, `requests`, `sounddevice`, `numpy`, `rich`, `json`, `os`
